# 1007_15 EDA — 시세 요인 그림과 PPT에 쓸 것

- 상태: 정리 (2026-10-08). PPT 데이터·시세 요인·자체 검증 장에 쓸 그림 선택
- 노트북: `notebooks/05_EDA_시세요인.ipynb`(생성 `notebooks/make_05_eda.py`, 정제 데이터와 저장된 검증 예측만 읽음), 그림 `outputs/figures/eda_*.png` 19개
- 대상: 평가 권역(강서는 화곡동)의 최근 3년 거래 12,100건(2026 공시가격 비율 11,742건). 거래량·시점 지수는 6년 28,461건. 가격은 구별 시점 지수로 기준일 환산
- 색: 권역 3개는 고정 순서 3색(모든 쌍 색각 구별 검증 통과, `dataviz` 검증 스크립트), 값 크기는 파랑 한 가지 색의 진하기, 상관은 파랑–회색–빨강

## 1. 무엇을 그렸나

| 묶음 | 그림 | 조합 |
|---|---|---|
| A 데이터 개요 | 월별 거래량(A1), 권역별 ㎡당 가격(A2), 면적·연식 분포(A3) | 권역 × 시간 / 가격 / 면적 / 연식 |
| B 공시가격과 시세 | 실거래가 vs 공시가격(B1), 변수 하나씩의 설명력(B2), 실거래/공시 비율 분포(B3), 시점 지수(B4) | 권역 × 공시가격 / 비율 / 시간 |
| C 시세 요인 | 연식(C1), 층(C2), 면적(C3), 역 거리(C4), 승강기(C5), 땅값(C6), 세대수(C7), 연식 × 면적 히트맵(C8), 지도(C9), 변수 상관(C10), 거래유형(C11) | 요인마다 권역 × (㎡당 가격, 실거래/공시 비율) 두 지표 |
| D 검증 요약 | 추정 vs 실제 + 신뢰도 신뢰성 그림(D1) | 권역 × 상황 A·B |

- 요인을 ㎡당 가격과 **실거래/공시 비율** 두 가지로 본 이유: 비율은 모델(B1)이 쓰는 값이라, 비율이 요인에 따라 달라지면 "공시가격만으로는 부족하고 그 요인으로 보정해야 한다"는 근거가 된다(ML 보정, 1007_10)

## 2. 확인한 사실(그림 제목의 근거)

| 그림 | 사실 |
|---|---|
| A1 | 연 거래량 2021년 7,614건 → 2023년 3,116건(최저) → 2025년 4,072건 |
| A2 | ㎡당 가격 중앙값 강남 1,589만 원, 관악 677만 원, 화곡 499만 원 — 강남은 화곡의 3.2배, 표준편차도 가장 큼(739만 원) |
| A3 | 면적 중앙값 강남 33.6㎡로 가장 작다(소형 비중), 연식 중앙값 관악 24년·화곡 18년·강남 13년 |
| B1 | log 실거래가와 log 공시가격의 결정계수 **0.87**, 비율 중앙값 **1.76**(공시가격은 시세의 약 57%) |
| B2 | 변수 하나만으로 설명하는 비율: 공시가격 0.87 > 면적·권역·땅값·연식·역 거리·층을 모두 합친 것 0.72 > 권역 0.42 > 땅값 0.37 > 면적 0.11 > 연식 0.03 |
| B3 | 비율 중앙값 화곡 1.68 · 관악 1.80 · 강남 1.88. 강남은 10～90% 범위 1.41～2.66으로 가장 넓다 |
| B4 | 기준월(2026-08) 대비 화곡은 2022년 1.07배 고점, 강남은 2024년 0.80 → 2026년 1.0으로 상승 |
| C1 | **새 건물일수록 ㎡당 가격이 높지만, 실거래/공시 비율은 오래된 건물이 더 높다**(강남 6～10년 1.76 → 31～35년 2.12, 관악 1.68 → 1.92). 공시가격이 노후 건물의 시세를 덜 따라감 — 재개발 기대 가격으로 보이며, 연식 보정이 필요한 이유 |
| C2 | 지하는 ㎡당 가격이 2층의 54～59%, 5층 이상은 신축 고층이 많아 비쌈. 비율은 지하·1층이 높다(강남 지하 2.44 vs 2층 1.88) — 공시가격이 저층을 더 낮게 평가 |
| C3 | 작을수록 ㎡당 가격이 높다(화곡 20㎡ 이하 797만 원 vs 60～85㎡ 404만 원) |
| C4 | 역 거리 효과는 약하다(log 역 거리와 ㎡당 가격 상관 −0.11). 화곡만 멀수록 뚜렷하게 쌈 |
| C5 | 승강기 있는 건물이 ㎡당 1.4～1.9배 비싸다. 다만 승강기 건물의 연식 중앙값 9～10년 vs 없는 건물 24～31년 — 연식과 겹친다(상관 −0.78) |
| C6 | 땅값과 ㎡당 가격 log 상관 0.69 |
| C7 | 세대수가 많을수록 대체로 ㎡당 가격이 높다(화곡 5～8세대 411만 원 vs 20～30세대 786만 원) |
| C8 | 같은 권역 안에서도 연식·면적 조합에 따라 2～3배(화곡 965만 vs 337만 원) |
| C10 | 연식–승강기 −0.78, 연식–지상층수 −0.73, 층–지상층수·승강기–지상층수 0.65 |
| C11 | 직거래의 비율 중앙값 1.69 vs 중개거래 1.77, 10% 지점 1.31 vs 1.45 — 낮은 쪽으로 치우침. 예측이 높게 빗나가는 이유(1007_13) |
| D1 | 상황 B 검증 632건 중 80%가 ±20% 안, 신뢰도 5분위 평균과 실제 적중률이 비슷하거나 실제가 약간 높음(보수적) |

## 3. PPT에 쓸 그림(제안)

| PPT 항목 | 그림 | 전달할 말 |
|---|---|---|
| 2 데이터 소스 | A1 | 6년 수집, 시장 사이클이 커서 최근 3년만 학습 |
| 3 시세 요인 | **B1**, **B2** | 공시가격 하나가 가격의 87%를 설명 → 모델의 뼈대 |
| 3 시세 요인 | **C1**, C2 | 공시가격이 덜 반영한 것(노후 건물·저층)을 보정해야 한다 → ML 보정 |
| 3 시세 요인 | C8 또는 C9 | 같은 권역 안에서도 위치·연식·면적에 따라 2～3배 |
| 3 시세 요인(버린·약한 변수) | C4, C10 | 역 거리는 약하고, 연식·승강기·층수는 겹친다 |
| 4 모델 설계 | B4 | 시점 지수로 과거 거래를 기준일 가격으로 옮김 |
| 5 자체 검증 | **D1**, C11 | 80%가 ±20% 안, 신뢰도가 정직함 / 직거래가 큰 오차의 원인 |

- 나머지(A2·A3·B3·C3·C5·C6·C7)는 부록 또는 질문 대비

## 한계

- 요인별 그림은 한 요인씩 본 것이라 다른 요인과 섞여 있다(예: 승강기 효과의 상당 부분은 연식). 요인 효과의 크기는 모델(XGBoost 중요도, 1007_14)로 말한다
- 그림 제목의 주장은 처음 초안에서 데이터와 다른 것이 6개 있었다 — 수치 표와 대조해 고쳤다(AI 활용 기록)
