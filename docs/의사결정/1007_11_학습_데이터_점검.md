## 3. 일괄 매매 기준을 3배로 둔 이유

- 예비 규칙(호 비율 > 공시가격의 2.5배, 묶음 합계로는 0.8~3.5배)은 133건을 잡았는데, 열어 보니 대부분 정상 거래였다
  - 묶음에서 1건만 높은 경우(39묶음): 다른 호가 우연히 같은 날 같은 금액에 거래된 것
  - 신사동 원빌라·논현동 논현타운: 층만 다른 같은 면적 호들이 같은 금액 — 묶음이 2호든 3호든 ㎡당 가격이 같아(원빌라 2,325만~2,329만 원) **합계가 아니라 호 단가**(신축 분양)
- 기준을 시장 중앙값의 2.5배로 하면 원빌라(2.50~2.54배)가 걸리고, 3배로 하면 합계가 확실한 두 묶음(3.67배·3.90배)만 남는다
- 기준은 2026 공시가격 거래의 비율 중앙값(시장 수준)으로 통일했다. 보충 연도 공시가격 거래끼리 비교하면 보충 연도의 높은 비율(1007_04)과 겹쳐 합계 묶음을 놓쳤다
- 대안: 묶음을 1건으로 줄이기 — 합계 금액이 그대로 남아 의미 없음 / 합계를 호 수로 나눠 살리기 — 호별 배분 기준(면적·층)이 없어 추정이 됨
- 바꾸는 조건: 블라인드 검증 대상 같은 최근 거래에 비슷한 묶음이 많이 보이면 규칙을 다시 본다

## 5. 모델 선정에 주는 영향

- 방법: 상위 후보 7개(B1, XGB·RF × 직접·잔차·평균)를 고정 하이퍼파라미터로 수정 전·후 데이터에서 다시 학습해 같은 최종 검증(상황 A·B·T)에서 비교. 수정 후는 예비 규칙(일괄 133건 제외)으로 더 많이 뺀 데이터 — 더 강하게 바꿔도 선정이 유지되는지 본 것
- 결과(상황마다 ±20% 적중률·MAPE·중앙값 오차 순위 평균): XGB-평균 2.6 → **2.1**(1위 유지), 가장 나쁜 순위 3.3 → 2.3. 지표 변화는 대부분 ±1%p 이내(부트스트랩 95% 구간 ±2%p 안)
- 예상대로 직접 방식이 가장 많이 바뀜(재건축 전 거래는 공시가격이 없어 직접 방식 학습에만 들어갔음): XGB-직접 상황 T 중앙값 오차 11.0% → 10.5%
- 판단: 1007_10의 선정(XGB-평균)은 유지. ML 비교 전체 재실험(85분)은 하지 않는다. `outputs/ml_*.csv`·노트북 03은 수정 전 데이터의 기록으로 둔다
