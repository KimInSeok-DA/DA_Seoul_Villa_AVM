## 2. 오차를 설명하는 변수 — 오차 점수

- 방법: |log 오차|(대략 오차율)를 예측 시점에 아는 변수로 최소제곱 회귀한 예측값을 "오차 점수"로 쓴다

| 변수 | 계수 | 뜻 |
|---|---|---|
| 동네(법정동·구) 비율의 흩어짐 | +0.62 | 동네 거래들의 실거래/공시 비율이 제각각이면 오차가 큼 |
| 같은 건물 비율의 흩어짐 | +0.21 | 같은 건물 거래끼리도 비율이 다르면 오차가 큼 |
| 같은 건물 비율과 동네 비율의 차이 | +0.17 | 건물만 유독 다르면 그 차이가 진짜인지 불확실 |
| log 전용면적 | −0.06 | 소형일수록 오차가 큼(32㎡ 이하 중앙값 오차 14.6% vs 62㎡ 초과 10.8%) |
| 같은 건물 근거·log(1+거래 수) | −0.03·−0.02 | 같은 건물 거래가 있고 많을수록 오차가 작음 |
| 강남구·화곡동(기준 관악) | +0.02·+0.01 | 강남은 고급·대형이 섞여 오차가 큼 |
| 면적 비어 추정 | +0.01 | 공시가격 호 면적으로 채우면 실제 면적과 맞는 비율 55% |

- 근거: 변수 하나씩으로는 순위상관이 0.1 안팎으로 약하지만, 합친 점수는 교차 적합(자기 폴드를 뺀 계수)으로 순위상관 0.20, 점수 10분위에서 중앙값 오차가 9.1% → 18.5%로 단조 증가
- 대안: 근거 수준(같은 건물/법정동/구)만으로 나누기(기존) — 같은 건물 10.6% vs 법정동 12.6%로 차이가 작아 신뢰도를 가르지 못함 / 그래디언트 부스팅 같은 비선형 모델 — 설명이 어렵고 표본 1만 건에 이득이 작을 것으로 판단. ML 비교 단계에서 다시 검토
- 바꾸는 조건: 건물 변수(연식·승강기·세대수)나 ML 모델을 넣어 오차 구조가 달라지면 변수 목록을 다시 정한다

## 3. 구간과 신뢰도

- 구간: 점수 10분위마다 log 오차의 10%·90% 분위수 → `price_low = 추정 × exp(−q90)`, `price_high = 추정 × exp(−q10)`. 정규분포 가정 없이 실제 오차 분포를 그대로 쓰므로 비대칭(실거래가 추정보다 높은 쪽 꼬리가 더 김)도 반영된다
- 신뢰도: 점수 10분위마다 **±20% 적중률**. 점수가 클수록 낮아지게 인접 구간 평균으로 단조 보정(isotonic)
  - 정의: "검증에서 비슷한 조건의 추정이 실거래가 ±20% 안에 든 비율"
  - ±20%를 고른 이유: 1007_07의 목표 지표이고, 값이 0.5~0.8에 퍼져 구분력이 있다. ±10%로 하면 0.26~0.54(보정 표본 점수 10분위)로 낮아져, 대부분 물건이 신뢰도 0.5 미만으로 나와 읽기 어렵다
- 검증으로 확인 못 한 조건: 홀드아웃 입력에는 호가 없어(실거래에 호 없음) 호 불일치·공시가격 근사의 효과를 잴 수 없다 → 기존 감점(0.05·0.10)을 그대로 뺀다. 공시가격이 없는 ㎡단가 추정은 보정 표본이 20건(5개 건물)뿐이라 구간은 기존 규칙(정규분포 가정, 보정 표본 포함률 70%)을 두고, 신뢰도는 **0.10으로 고정**한다 — 보정 표본 ±20% 적중 2/20건(10%), 중앙값 APE 41%, 최종 검증 4건 중 0건. 같은 ㎡단가 방식을 모든 건물에 쓴 기준선 B0(±20% 적중 36%)보다 훨씬 나쁘다
- 대안: 정규분포 가정(추정 × exp(±1.28 × 표준편차)) — 기존 방식, 꼬리를 과소평가해 포함률 60%대 / 분위수 회귀로 연속 구간 — 10분위 표가 설명·검산이 쉬워 표를 택함
