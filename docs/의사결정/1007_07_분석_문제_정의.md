# 1007_07 분석 문제 정의와 검증 설계

- 상태: 확정 (2026-10-07). 성공 기준은 바꾸지 않고 최종 모델 결과와 대조했다(§5)
- 위치: 모델을 만들기 전에 목표·지표·검증 분할을 고정한다(검증 데이터를 보고 판단하는 누수를 막기 위해)

## 1. 실무 문제 → 분석 문제

| 구분 | 내용 |
|---|---|
| 실무 문제 | 권역 안 임의의 다세대·연립 호(지번·층·호)의 매매 시세를 자동으로 낸다. 빌라는 건물당 거래가 드물고(지번당 평균 3.7건), 실거래에 호가 없다 |
| 예측 대상 | **호 단위 매매 시세(원)**, 산출 기준일 **2026-10-06** |
| 목표 변수(모델 내부) | 기준일로 시점 보정한 **로그 ㎡당 단가** 또는 **로그 실거래가/공시가격 비율**. 추정 후 면적(또는 공시가격)을 곱해 원 단위로 되돌린다 |
| 출력 | `price_est`, 80% 구간 `price_low`·`price_high`, `confidence`(0~1), `basis`(근거 한 줄), `status` |
| 권역 | 강서구 화곡동, 관악구 전체, 강남구 전체. 그 밖은 `fail`(권역 밖) |
| 제약 | 20건 30분 이내, 입출력 규격 고정, API 키는 환경변수, 결과 저장 금지 API는 실시간 조회만(1006_04), 코드에 특정 물건 분기 금지(1006_03) |

## 2. 평가 지표

평가자 기준(실거래 대비 오차율, 실패 건수, 신뢰도와 실제 오차의 일치)에 맞춘다.

| 지표 | 정의 | 왜 |
|---|---|---|
| APE | \|추정 − 실제\| / 실제 | 과제가 오차율을 본다 |
| MAPE, 중앙값 APE | APE의 평균·중앙값 | 평균은 큰 오차에 민감, 중앙값은 전형적 오차 |
| ±10%, ±20% 적중률 | APE ≤ 0.1, ≤ 0.2 비율 | 실무에서 읽기 쉬운 지표 |
| 구간 포함률 | 실제가 `price_low`~`price_high` 안에 든 비율 | 80% 구간이면 80% 근처여야 정직 |
| 신뢰도 구간별 APE | `confidence` 구간별 중앙값 APE | **신뢰도가 높을수록 오차가 작아야**(단조 감소) |
| 실패율 | `fail` 비율(권역 안 입력 기준) | 실패 0을 목표 |

실제값: 홀드아웃 거래의 실거래가를 시점 지수로 기준일 가격으로 보정한 값. 블라인드 검증 물건도 최근 12개월 거래라 보정 폭은 작다.

## 3. 검증 분할 (홀드아웃)

- 후보: 평가 권역 안에서 **최근 12개월(기준일에서 12개월 전 다음 날부터: 2025-10-07 ~ 2026-10-06)에 거래가 있는 건물(PNU)** 3,159개 — 블라인드 검증 물건의 추출 조건과 같다
- 분할: 그중 **20%(632개)를 무작위(시드 42)로 검증 건물**로 고정 → `data/processed/holdout_pnu.csv`
- 검증 대상 거래: 검증 건물마다 최근 12개월 중 **가장 최근 거래 1건**(큰 건물이 결과를 좌우하지 않게)
- 두 가지 상황을 함께 보고(1006_03):
  - **A. 처음 보는 건물**: 검증 건물의 모든 거래를 학습·비교사례·시점 지수·비율 통계에서 뺀다 → 가장 엄격
  - **B. 같은 건물 과거 거래 있음**: 검증 건물의 거래 중 대상 거래 **이전** 거래만 남긴다 → 실제 블라인드 상황에 가까움
- 누수 방지: 시점 지수·비율 통계는 학습 데이터로만 계산한다
- 한계: 이상치 제외(1007_04)는 정제 단계에서 전체 데이터로 했으므로, 검증 대상 기간의 낮은 이상치 35건(같은 기간 거래의 0.7%)은 검증 대상에 들어가지 않는다. 블라인드 검증에는 이런 저가 거래가 나올 수 있어 우리 오차가 약간 낙관적일 수 있다

## 4. 성공 기준 (잠정)

| 지표 | 목표 |
|---|---|
| 실패율(권역 안) | 0% |
| 중앙값 APE | 10% 이하 |
| ±20% 적중률 | 75% 이상 |
| 80% 구간 포함률 | 70~90% |
| 신뢰도 구간별 오차 | 단조 감소 |

근거: 공시가격 비율의 집단 내 퍼짐(로그 MAD 기반 표준편차 약 0.14, 1007_04)으로 볼 때 같은 구 비율만 써도 중앙값 오차가 10% 안팎일 것으로 예상. 기준선 결과를 보고 조정한다.

## 대안

- 시간 기준 분할(최근 12개월 전체를 검증): 실제 예측 때는 최근 시세를 쓰므로 오차를 과대평가 → 보조 지표로만
