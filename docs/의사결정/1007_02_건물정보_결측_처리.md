# 1007_02 건물 정보(표제부)가 없는 지번의 결측 처리

- 상태: 확정 (사용자 결정, 2026-10-07) → **학습 거래 처리 변경 (사용자 결정, 2026-10-08, [1008_02](1008_02_철거된_건물_거래.md))**: 폐쇄말소대장으로 113개가 실제 말소된 건물임을 확인하고, 말소일 이전 거래 523건은 학습에서 제외. 건물 정보 결측 처리(아래)는 예측용 `bld_title.csv`에 그대로 둔다

## 배경

매매 지번 9,928개 중 118개는 건축물대장 표제부 조회 결과가 "건물 0건"이다(오류 응답 아님). 이 지번들의 매매는 555건(해제 제외 거래의 1.6%), 그중 최근 12개월 거래는 50건이다.

## 원인 확인

| 근거 | 결과 |
|---|---|
| 표제부 응답 | 118개 모두 건물 0건 |
| 공시가격이 마지막으로 나온 해 | 112개가 2025년 이전에 끊김(2020년 9, 2021년 30, 2022년 23, 2023년 22, 2024년 14, 2025년 14), 2026년 5, 없음 1 |
| 마지막 거래 연도 | 2021년 56개로 최다 |
| 2026년 공시가 있는 5개를 Kakao 주소검색 | 4개는 도로명 주소 없음, 1개(삼성동)만 건물 확인 |

→ 대부분 **거래 후 철거(재건축·재개발)되어 현행 건축물대장에서 폐쇄말소대장으로 옮겨진 건물**로 판단한다. 소수는 대장이 다른 지번으로 등록된 경우로 보인다.

## 검토한 안

| 안 | 장점 | 단점 |
|---|---|---|
| 모두 NULL로 둠 | 단순, 틀린 값 없음 | 다른 자료로 알 수 있는 층수·세대수까지 버림 |
| **항목별로 대체 가능한 것만 채우고 나머지는 NULL + 출처 표시 (채택)** | 공시가격에서 층·호 수를 얻을 수 있어 정보 손실이 작음. 출처 열로 대체 여부를 구분 가능 | 공시가격 층·호 수는 대장 값과 정의가 다를 수 있음(근사치) |
| 폐쇄말소대장 API로 다시 조회 | 원래 대장 값을 얻을 수 있음 | 새 API 신청이 필요하고, 대상 대부분이 오래된 거래라 효과가 작음 → 10-08 서울시 폐쇄말소대장 Open API로 조회(1008_02) |
| 해당 거래를 학습에서 제외 | 결측이 사라짐 | 비교사례·시점 지수에 쓸 실거래 555건을 버림 → 10-08 채택(1008_02): 철거 직전 매집처럼 이례적인 거래가 많고, 최근 3년 학습 데이터의 0.8%라 손실이 작음 |

## 결정

| 항목 | 처리 |
|---|---|
| 건축년도 | 모델 단계에서 실거래 `buildYear` 사용(실거래에는 항상 있음) |
| 지상·지하 층수, 세대수 | 공시가격(가장 최근 연도)의 최고 층·최저 층·호 개수로 채움 |
| 승강기, 주차, 사용승인일, 구조, 연면적 | NULL |
| 출처 | `title_source` = `건축물대장` / `공시가격 대체` / `없음` |
| 폐쇄말소대장 | 조회하지 않음 |

결과: 건축물대장 9,810 / 공시가격 대체 117 / 없음 1. 매매와 조인 시 거래 기준 건축물대장 34,254 / 공시가격 대체 554 / 없음 1.

## 모델에서

- 비교사례법은 승강기 등이 없어도 산출 가능(위치·면적·연식·층으로 비교)
- ML 보정 단계는 NULL을 그대로 받는 모델(LightGBM 등)을 쓰거나 `title_source`를 변수로 넣는다
- 블라인드 검증 물건(최근 12개월 거래)은 99.1%가 표제부를 가지고 있어 영향이 작다
