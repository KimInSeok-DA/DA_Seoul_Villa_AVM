# 1006_01 협업 템플릿 적용 범위

- 상태: 확정
- 배경: 이전 팀 프로젝트에서 쓴 AI 협업 템플릿을 이 과제에 접목. 단, 이번 과제는 **1인·3일·제출물 고정**이라 팀 정본 동기화 규칙은 필요 없다.

## 가져온 것

| 템플릿 항목 | 적용 |
|---|---|
| `HANDOFF.md` | 루트에 둔다. 현재 상태·다음 작업·열린 결정만 |
| 일일인계 `YYYY-MM-DD.md` | `docs/작업일지/`. 그날 한 일·확인한 사실·결정, 추가만 |
| 의사결정 파일명 `MMDD_NN_주제.md` | `docs/의사결정/` |
| 작업 등급별 모델·추론 강도 안내 | `AGENTS.md`에 요약 |
| `outputs/` vs `milestones/` 구분 | 그대로. 모델 선정·홀드아웃 결과는 메타데이터와 함께 `milestones/` |
| 고정된 실제값·예측값 CSV를 그래프의 정본으로 | 그대로 (PPT 그림을 모델 재학습 없이 다시 그릴 수 있게) |
| AI attribution 차단 | `.claude/settings.json` + `.githooks/` (commit-msg 제거, pre-push 차단) |
| 같은 사실을 두 곳에 쓰지 않는다 | 그대로 |

## 뺀 것과 이유

- **주간요약·작업로그 폴더**: 3일짜리라 필요 없음
- **팀 정본·`출처/` 해시 대조, 백업 브랜치 정렬**: 1인 저장소라 해당 없음
- **분석 단계별 `작업과정/<단계>/` 하위 폴더**: 3일짜리라 폴더가 내용보다 많아진다
- **한글 폴더명(코드 쪽)**: `src/`, `data/` 등 코드가 import·경로로 쓰는 폴더는 영문. 문서 폴더만 한글
