# 1007_06 거래 지번 좌표와 개별공시지가

- 상태: 확정 (사용자 결정, 2026-10-07)
- 코드: `src/collect_parcels.py` → `data/reference/parcels.csv`

## 배경

지하철역 거리와 반경 내 비교사례를 만들려면 거래 지번의 좌표가 필요하다. Kakao·VWorld 지오코더는 결과 저장이 금지라 쓸 수 없다(1006_04 5절).

## 검토한 안

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 연속지적 전국 파일(data.go.kr 15125044) | VWorld에서 shp 다운로드 | 한 번에 받음 | 전국 3,961만 필지로 매우 큼. **공공누리 제4유형(변경 금지)** → 좌표를 뽑아 가공한 파일을 공개하기 어려움 |
| **연속지적도 API(data.go.kr 15056910, VWorld `LP_PA_CBND_BUBUN`) (채택)** | 법정동별로 필지 경계를 받아 중심점 계산 | 필요한 3개 구만, **이용허락범위 "제한 없음"**, PNU로 바로 연결, 이미 가진 VWorld 키 | 경계 도형에서 중심점을 직접 계산해야 함 |
| 좌표 없이 비교(B안) | 같은 법정동·지번 번호 근접 | 빠름 | 지하철역 거리를 못 씀, 반경 비교 불가 |
| 지오코더로 받아 저장 | — | — | 약관 위반이라 제외 |

## 결정과 근거

- 연속지적도 API로 **권역 3개 구 30개 법정동의 모든 필지**(123,615필지)를 받는다. 거래 지번뿐 아니라 블라인드 검증에 들어올 어떤 지번도 미리 좌표가 준비되어, 예측 중 외부 조회가 필요 없다
- 경계 도형은 저장하지 않고 **중심점 좌표와 속성만** 남긴다(8.7MB, 수집 약 4분)
- 응답에 **개별공시지가(㎡당 땅값)**가 함께 있어 입지(단지외부) 요인의 대리 변수로 쓴다(1006_02에서 선택 데이터로 적어 둔 항목)
- 크기 확인 후 B안으로 전환할 수 있게 두었으나(사용자 조건), 크기·시간 모두 작아 그대로 진행

## 오류와 수정 (품질 점검에서 발견)

- 처음 중심점 계산에서 경위도(126, 37)를 그대로 넓이 공식에 넣어 **자릿수 손실로 중심점이 필지 밖(약 58m)으로 나갔다**. 봉천동 1597-30을 이전 지오코딩 위치와 대조해 발견
- 수정: 첫 꼭짓점을 원점으로 옮겨 계산하고, 결과가 외곽선 범위 밖이면 꼭짓점 평균을 쓰도록 안전장치 추가 → 전체 재수집

## 대안과 바꾸는 조건

- 중심점 대신 건물 출입구 좌표(도로명주소 위치정보 DB)를 쓸 수 있다 → 큰 필지(단지형)에서 역 거리 오차가 문제 될 때
- 개별공시지가가 결측인 필지는 같은 법정동 중앙값으로 채우거나 결측 표시 → 모델 단계에서 결정
