## 1. 크게 틀린 물건의 원인

|---|---|---|---|---|---|
| 공시가격 대비 보통 거래(\|수정 Z\| ≤ 1) | 441 | 6.2% | 93.4% | −0.1% | 0.81 |

| 공시가격 대비 비싸게 거래(z > 1) | 120 | 16.8% | 58.3% | **−18.5%**(낮게 추정) | 0.72 |

| ML 보정 배율 1.1 초과 | 92 | 13.6% | 65.2% | −6.9% | 0.67 |

- **가장 큰 원인은 모델이 아니라 거래 자체다.** ±20% 밖 125건 중 77%가 공시가격 대비 이례적인 거래(싸게 37%, 비싸게 40%, 한 건에 여러 원인 가능). 같은 건물·동네의 비율로는 설명되지 않는 가격이다
- 오차 상위 15건은 **모두 실제보다 높게 추정한 싼 거래**이고 10건이 직거래(예: 대치동 24.67㎡ 1.8억 vs 추정 3.65억, 청담동 직거래 3.89억 vs 7.49억). 공시가격보다 싸거나 비슷하게 거래된 경우가 많아 특수관계 거래·급매로 보인다. **거래유형은 입력에 없어** 예측 시점에 알 수 없다
- 지하층·30년 초과 건물은 오차가 크다 → 신뢰도에 반영(§2)
- 강남의 낮은 추정(상황 A −4.4%, B −4.8%)은 강남 고유의 수준 차이가 아니다. 강남 안에서도 4억 이하는 높게(+3.7～5.8%), 4억 초과는 낮게(4～7억 −5.2%, 7억 초과 −7.5%) 추정하고, 관악도 2.5억 이하 +10.3%·7억 초과 −8.9%로 같은 모양이다(노트북 04 §3, 상황 B). 비싼 물건을 낮게·싼 물건을 높게 보는 **평균으로 끌리는 경향**이고, 강남에 비싼 거래가 많아 평균이 낮게 나온다
  - 시점 지수의 지연은 아니다: 강남 2026-08 원값 0.642 vs 지수 0.622(약 −2%)
- 대안(고치지 않은 이유): 직거래를 학습에서 빼기 — 블라인드 물건도 직거래일 수 있어(검증 대상 10%) 빼면 그 경우 더 틀림 / 평균으로 끌리는 경향 보정(가격대별 배율) — 입력에 실거래가가 없어 가격대를 추정값으로 나눠야 하고, 그 배율을 검증 데이터로 정하면 과적합

## 2. 신뢰도에 지하층·노후 반영

- 방법: 오차 점수 변수에 `basement`(지하층)·`old`(30년 초과) 추가 후 같은 절차로 재보정(1007_09)
- 근거(보정 표본 10,088건, 최종 검증과 분리): 지하층 ±20% 적중 59% vs 지상 74%, 30년 초과 67% vs 75%인데 기존 신뢰도는 지하 0.68·30년 초과 0.69로 비슷하게 매김. 변수를 넣으면 교차 적합 순위상관 0.240 → 0.252, 지하 신뢰도 0.68 → 0.61(실제 0.59), 30년 초과 0.69 → 0.67(실제 0.67)
- 결과(최종 검증): 지하층 평균 신뢰도 A 0.61·B 0.64 vs 실제 ±20% 적중 48.8%·51.2% — 이전(0.65～0.67 vs 45～46%)보다 가까워졌지만 아직 10%p 남짓 높다. 검증 표본의 지하층이 41건이라 표본 변동 범위로 본다
- 대안: 가격대·직거래 변수 — 입력에 없어 쓸 수 없음

## 3. 학습 기간 3년

- 방법: 같은 최종 모델 경로로 학습 거래를 기준일부터 3·5·6년으로 바꿔 최종 검증에서 비교(구간·신뢰도 보정 전 추정값). 검증 대상 거래는 셋 모두 같다

| 기간 | 학습 거래 | A ±20% / 중앙값 / 평균 | B ±20% / 중앙값 / 평균 | B 같은 건물 근거 |
|---|---|---|---|---|
| **3년** | 14,520 | **79.0% / 9.3% / 13.7%** | **80.2% / 9.0% / 13.0%** | 59.7% |
| 5년 | 24,531 | 79.0% / 9.7% / 14.0% | 78.5% / 9.3% / 13.4% | 73.6% |
| 6년 | 33,886 | 74.5% / 9.9% / 14.8% | 78.2% / 9.5% / 13.9% | 82.1% |

- 부트스트랩 95% 구간(건물 재표본 2,000번): 3년 − 6년 ±20% 적중 A **+4.4%p [+2.2, +6.8]**·B +2.1%p [−0.2, +4.3], 평균 오차 A **−1.1%p [−1.5, −0.6]**·B **−0.9%p [−1.3, −0.4]**. 3년 − 5년 평균 오차 A **−0.3%p [−0.6, −0.0]**·B **−0.4%p [−0.7, −0.1]**
- **최종 검증과 분리한 보정 표본(10,088건)에서도 같은 방향**: ±20% 적중 6년 72.5% → 3년 75.9%(A 70.7 → 74.7%, B 74.3 → 77.2%), 중앙값 오차 11.2% → 10.4%. 같은 검증 세트로 고른 선택 편향이 아님을 확인
- 근거: 오래된 거래일수록 시점 보정으로 기준일 가격으로 옮기는 오차가 커진다. 3년으로 줄이면 같은 건물 근거를 쓰는 비율이 82% → 60%로 줄지만 그래도 더 정확하다 — "같은 건물의 오래된 거래"보다 "동네의 최근 거래"가 낫다
- 대안: 5년 — 처음 보는 건물 적중률은 같지만 평균 오차가 유의하게 크다 / 2년 이하 — 시험하지 않음. 동네(법정동) 통계 거래 수가 줄고(최소 20건 기준) 시점 지수의 월 표본이 작아진다
- 바꾸는 조건: 시장 변동이 커져 최근 거래만으로 동네 비율이 불안정해지면(법정동 기준 미달 증가) 기간을 늘린다. 재학습할 때마다 같은 비교로 확인
- 모델 선정(1007_10, 6년 데이터)은 다시 하지 않았다: 기간은 모든 후보에 똑같이 적용되는 조건이고, 데이터 수정(1007_11) 때 상위 후보 순위가 바뀌지 않은 것과 같은 이유
