# 1006_04 데이터 수집 범위

- 상태: 확정 (사용자 결정, 2026-10-06). 5번(지하철역 출처)은 2026-10-07 이용약관 문제로 공공데이터로 교체

## 1. 연립 포함

- 결정: 다세대와 함께 연립도 수집·학습한다. PPT에 포함 사실을 적는다
- 근거: 과제가 연립 포함을 허용(포함 여부만 명시하면 됨). 실거래 API가 연립·다세대를 한 번에 주고 `houseType`으로 구분된다. 매매 36,997건 중 연립 3,548건 — 표본이 늘고, 다세대만 쓰고 싶으면 언제든 걸러낼 수 있다
- 주의: 검증 물건은 다세대다. 연립은 면적·연식 분포가 달라 `house_type`을 변수로 두거나 비교사례에서 다세대를 우선한다

## 2. 수집 기간 6년 (2020-10 ～ 2026-10)

- 결정: 처음 계획(최근 2～3년)보다 넓게 받는다. 실제 학습 기간은 홀드아웃 비교로 정한다
- 근거:
  - 3년은 로드맵 초안의 숫자를 근거 없이 따른 것이었다(사용자 질문으로 재검토)
  - 호출 수가 432회로 한도(일 10,000) 대비 부담이 없다
  - 빌라는 건물당 거래가 드물어(지번당 평균 3.7건) 기간이 길수록 같은 건물 사례가 늘어난다
  - 시점 보정 지수를 안정적으로 만들 수 있다
- 주의: 2021～22 고점, 2022 하반기 하락, 2023 전세사기 여파가 모두 들어 있어 구별 시점 보정이 필수다

## 3. 권역 밖 강서구(화곡동 외)도 수집

- 결정: 실거래 API가 구 단위로 주므로 강서구 전체를 받고, 화곡동 외 지번(1,361개)도 건물 정보까지 수집한다
- 근거: 화곡동 경계 근처 물건의 비교사례와 강서구 시점 지수에 쓸 수 있다. 제외해도 절약되는 시간이 약 40분으로 작다(사용자 판단)

## 4. 전월세 수집

- 결정: 매매와 같은 범위로 수집하되, 가격 산출이 아니라 신뢰도 점검용 보조 근거로만 쓴다(1006_02)
- 근거: 거래가 적은 건물의 가격 수준을 확인하는 데 쓸 수 있다. 감정평가 실무에서도 주거용은 전세금을 가치와 직접 같게 보지 않는다

## 5. 지하철역 좌표 — 공공데이터로 교체 (10-07)

- 처음(10-06): 원문 6항에 지하철역 위치가 예시로 있어 포함(사용자 결정). 서울교통공사 파일(data.go.kr 15099316·15099317)은 권역 내 노선(9호선 1단계·신림선·수인분당선·신분당선·공항철도)이 빠져 있어, AI가 Kakao 로컬 카테고리 검색(SW8)으로 371개 역을 받아 `data/reference/subway_stations.csv`로 저장했고 PR #1로 공개 저장소에 올라감
- 문제(10-07, 근거 점검 중 발견): Kakao 로컬 API는 결과 저장(가공 포함)을 금지하고 실시간 호출만 허용한다. 과제도 각 사이트 이용약관을 지키라고 하고, 지하철역 위치는 공공데이터를 쓰라고 안내한다. Kakao·VWorld 지오코더는 주소를 좌표로 바꾸는 **실시간 도구**로만 쓸 수 있다
- 결정(사용자):
  - 역 좌표를 **전국도시철도역사정보 표준데이터**(data.go.kr, 2026-06-30 기준, 사용자가 내려받음)로 교체 → `src/build_stations.py`. 권역 주변 367개(역·노선), 275개 역, 24개 노선. 9호선 1단계·신림선·분당선·신분당선·공항철도 포함 확인. 노선마다 역 이름 표기가 달라(`한티역`/`선릉`, `양재(서초구청)`) 통일한 `station_key` 추가. 기준일자가 `1900-01-00`인 행 12개는 날짜만 결측
  - 공개 저장소의 Kakao 파일은 **새 커밋으로 교체·삭제**(A안). 이력에서 지우는 강제 푸시(B안)는 하지 않음 — PR 참조(`refs/pull/1`)에 남아 B안으로도 완전히 지워지지 않고, 내용이 역 이름·좌표라는 공개 사실 정보이며 같은 정보를 공공데이터로 대체했기 때문
  - Kakao 수집 스크립트 `src/collect_stations.py` 삭제, 로컬의 Kakao·VWorld 지오코더 응답 파일 삭제, `src/probe_apis.py`는 두 응답을 저장하지 않게 수정
- 앞으로: 예측 중 입력 주소 조회(PNU·좌표)에만 Kakao·VWorld를 실시간으로 쓴다. 거래 지번 좌표처럼 저장이 필요한 것은 공공데이터(연속지적도 등)를 쓰거나 좌표 없이 법정동 단위로 비교한다
